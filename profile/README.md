# 🎮 메이프로필 | MAYPROFILE

**레트로 게임 프로필로 소개하는 우리 팀의 이야기**

오픈소스SW활용 수업에서 팀원 6명이 함께 만드는 포트폴리오 웹사이트입니다. 팀원의 관심 분야와 기술 역량, 프로젝트 결과물, 함께 개발한 과정을 담습니다.

## 🕹️ 프로젝트 소개

레트로·게임프로필 콘셉트를 바탕으로 다음 내용을 소개합니다.

- 팀의 목표와 활동 방향
- 팀원 6명의 프로필
- 팀·개인 프로젝트 갤러리와 상세 소개
- 회의와 개발 과정의 활동 기록

HTML, CSS, JavaScript로 정적 웹사이트를 제작하고 GitHub Pages로 배포할 예정입니다.

## 👥 함께 만드는 사람들

- **황지호 | 팀장** - 메인 페이지, JavaScript 인터랙션, 저장소 관리, 배포, README
- **최유정** - 팀 소개, 공통 메뉴·내비게이션, 헤더·푸터
- **임재민** - 팀원 프로필, FAQ, 문의 안내
- **김현웅** - 프로젝트 갤러리·상세
- **김도현** - 반응형 디자인, 웹 접근성, 화면 테스트
- **권지원** - 프로젝트 검색·필터, 이미지·아이콘 관리

모든 팀원이 직접 구현하고 Issue 등록, PR 작성, 코드 리뷰에 참여합니다.

## 🌱 협업 방식

```text
feature/* → develop → main
```

- **feature/** - 기능별 작업
- **develop** - 개발 코드 통합 및 테스트
- **main** - 최종 검증을 마친 배포용 코드

작업은 Issue로 등록하고, PR과 팀원 리뷰를 거쳐 반영합니다.
